What is a network?
Network is a group of two or more devices which connect with each other to communicate among themselves.

What does a router do?
A router is a networking device used to connect the two or more different networks and forwards the data packets to the destination device. It works using the IP address of the devices by which the router sends the data packets to the destinated device.

What is an IP address?
IP address is the unique address provided to the device on a network. It helps in identifying the device and communicate with each other. There are two types of IP address 
1.	Public- it is assigned by the ISP to the device. And used to identify the device in the network.
2.	Private- it is used on local basis. It doesn’t connect with the internet.

What is MAC address?
MAC address is also know as physical address of the device. It is used to communticate in local area network.





How does data travel when I open google.com?
Data travel works through the TCP/IP protocol suite. It follows the following stages:
Stage 1: application layer- user sends the request www.google.com to the google server. DNS resolves google.com into an IP address. Then the browser uses HTTP/HTTPS to request the webpage.
Stage 2: transport layer- it handles the ports services. Two main ports TCP and UDP. The data packets adds the port number to identify on which port the data should travel.
Stage 3: network layer-  it handles the ip address of both client and the server. It ensures the data should reach to the destined server. The ip address identify the device to which the data should be received. 
Stage 4: data link layer- it contains the mac address the of the device and the router present in the network to make sure that the data travel through the right path. It also converts the data into bits so it can be reach into segments.

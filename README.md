# SOC-Bootcamp-Week1
SOC Analyst Week 1: Networking fundamentals, TCP/IP, OSI, network commands &amp; Wireshark

## Topics Covered
- Networking Fundamentals
- IP & MAC Addresses
- OSI & TCP/IP Models
- Common Ports & Protocols
- DNS, TCP & UDP
- Encapsulation & Decapsulation
- Network Commands: ping, tracert, nslookup, ipconfig
- Wireshark Packet Analysis

## Practical Work
- OSI Model Diagram
- TCP/IP Diagram
- Wireshark Traffic Captures

## Tools
- Wireshark
- Windows CMD

## Key Learning
Learned how data travels across networks and how basic network traffic can be captured and analyzed for SOC investigations.
